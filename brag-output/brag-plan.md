# Brag Plan: youtube-automation

## What is this app?
A faceless YouTube pipeline that runs entirely on GitHub Actions: pick a topic, and it writes the script, voices it, finds visuals, renders a 1080x1920 video and posts it - every 3 hours, with fallbacks at every stage so it always ships.

## The angle
No web UI to show - the product IS the machine. So the video shows the machine: the six-stage pipeline cascading on the beat, the fallback chains that make it unkillable, and the proof stats. Hook: "A YouTube channel that runs itself."

## Hook (first 2-3 seconds)
"A YouTube channel that runs itself." - white slam, then "runs itself." in YouTube red on the track's opening hit (0.27s strong cue).

## Key moments (the middle)
- Six pipeline stages cascade one by one: TOPIC / SCRIPT / VOICE / VISUALS / RENDER / UPLOAD with the real provider names.
- The fallback chain: Groq -> Gemini -> OpenRouter -> offline Qwen. Punch: "Zero API keys? Still ships a watchable video."
- Stat cards: 1080x1920, 8 arcs x 16 formats, every 3 hours.

## Outro / punchline
"youtube-automation - Faceless videos. Rendered and posted by GitHub Actions."

## User flow worth showing
Topic in -> script -> voice -> visuals -> render -> upload. The pipeline cascade is the flow; the repo is a CLI/Actions product, so there is no app screen to recreate.
