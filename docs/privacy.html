Privacy Policy - Personal YouTube Uploader

Effective date: October 1, 2026

This policy covers the personal YouTube upload authorization used by Hitansh Gopani for the Alpha Explorer channel.

Data used: The uploader processes the owner's OAuth client configuration and authorization tokens, prepared video files, titles, descriptions, tags, visibility settings, and the resulting YouTube video ID or URL. It does not invite other users to connect accounts or collect information from viewers through this OAuth flow.

Purpose: This data is used to authorize uploads and send the owner's prepared videos and metadata to YouTube. It is not sold or used for advertising profiles.

Services involved: Google receives OAuth requests and YouTube receives uploaded videos and metadata. GitHub Actions runs the automation. The refresh token is stored in a protected credential store and as a GitHub Actions secret. It is not published in the source repository or included in these pages. Prepared output files and metadata may be retained as workflow artifacts according to their configured retention. Published videos follow their selected YouTube visibility and YouTube's own policies.

Scope limit: This refreshed authorization requests youtube.upload only. It does not grant Gmail, Drive, contacts, analytics-readonly, or comment-management access. Optional video-generation services are outside this upload authorization and are not given this YouTube refresh token by the upload code.

Control and deletion: The owner can stop the automation, remove the saved authorization token from its credential stores, and revoke the app's access in Google Account settings. Revocation prevents future use of that grant. It does not delete videos already uploaded; those can be managed in YouTube Studio. Stored workflow outputs can be removed separately from the repository's Actions artifacts.

This is a personal-use tool, not a public user-data collection service. The owner maintains it through the source repository.
