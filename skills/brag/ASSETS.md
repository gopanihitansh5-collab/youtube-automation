# Assets

Music and SFX binaries are not vendored here (size). Get them from the upstream
repo: `git clone https://github.com/latent-spaces/brag` - they live under
`skills/brag/assets/` (CC0 SFX, bundled music tracks). Copy the ones a run uses
into `<output-dir>/composition/assets/` as `skills/brag/references/audio.md`
describes.
